# LocoTrack weights (download separately)

This directory is intentionally **not** included in the repository.

GPU mode needs pre-trained checkpoints here. After cloning, download:

| Model | File | Download |
|-------|------|----------|
| LocoTrack-S | `locotrack_small.ckpt` | [Hugging Face](https://huggingface.co/datasets/hamacojr/LocoTrack-pytorch-weights/resolve/main/locotrack_small.ckpt) |
| LocoTrack-B | `locotrack_base.ckpt` | [Hugging Face](https://huggingface.co/datasets/hamacojr/LocoTrack-pytorch-weights/resolve/main/locotrack_base.ckpt) |

CPU-only installs do not require these files.

See also `locotrack_pytorch/README.md`.
